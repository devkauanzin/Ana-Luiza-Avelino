# Dra. Analu – Odontopediatra (Curvelo/MG)

Landing page da Dra. Ana Luiza Avelino, mestre e especialista em Odontopediatria (CRO-MG 50073).

## Deploy
O `index.html` é autossuficiente (fotos e fontes embutidas). Basta publicar a raiz do repositório
como site estático (Vercel, Netlify, GitHub Pages, Hostinger...). Não há build obrigatório.

## Editar
1. Edite `src.html` (as imagens e fontes ficam em `img/`).
2. Gere o `index.html` final: `python3 build.py`.

Número do WhatsApp e mensagem padrão: no início do `<script>`, variáveis `WHATSAPP` e `MSG_PADRAO`.
